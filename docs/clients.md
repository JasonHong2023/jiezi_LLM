# 芥子客戶端 / Jiezi clients

> 規格 / Spec：`openspec/changes/add-cli`（cli）、`openspec/changes/add-gateway`（gateway）。

## 1. 啟動 gateway / Start the gateway

```bash
scripts/jiezi start        # 在背景啟動，關掉終端機也不會停 / background; survives closing the terminal
scripts/jiezi stop         # 停止 gateway 與引擎 / stop the gateway and the engine
scripts/jiezi logs         # 最近的記錄 / recent logs
scripts/jiezi status       # 狀態 / state
scripts/jiezi serve        # 前景執行（除錯用），Ctrl-C 關閉 / foreground (debugging); Ctrl-C stops it
```

`jiezi chat` 與 `jiezi ask` 發現本機 gateway 沒開時，會自動在背景啟動它。
`jiezi chat` and `jiezi ask` start the local gateway in the background when it is not running.

gateway 只綁 `127.0.0.1:36100`，所有請求都要帶 `.env` 裡的 `JIEZI_GATEWAY_KEY`（bootstrap 會自動產生；舊的安裝可用 `scripts/jiezi init-key`）。
The gateway binds only to `127.0.0.1:36100`; every request needs `JIEZI_GATEWAY_KEY` from `.env` (generated by bootstrap, or `scripts/jiezi init-key` on older installs).

## 1.0 附上文件 / Attaching documents

```bash
scripts/jiezi ask --file 報告.pdf "請摘要重點"          # PDF、.docx、.pptx、.xlsx、.html、.txt、.md；可重複 --file
cat 會議記錄.txt | scripts/jiezi ask "列出待辦事項"     # 管線輸入也當成文件
```

`jiezi chat` 裡輸入 `/file 路徑`，再輸入問題。文件會一直附著（狀態列顯示檔名），可以對同一份文件連續追問，每一題都會依那一題重新挑段落，也會參考上一輪問答（所以可以問「那相關數據呢？」）；`/file clear` 取消，重開 chat 後要重新 `/file`。掃描版 PDF 會自動用繁中 OCR（每頁約 2 秒）。PowerPoint 讀每張投影片的文字與備忘稿（整張是圖片的簡報讀不到字，請先匯出成 PDF）；Excel 每個工作表讀成「欄 | 欄」的列，日期會轉成 2026-11-16 這種寫法，公式取上次計算的結果，上限 20 萬個儲存格。舊版 .doc／.ppt／.xls 以及 .rtf、OpenDocument（.odt／.odp／.ods）會先用 LibreOffice 轉成新格式再讀（每份多花幾秒到十幾秒）；轉檔只在沒有網路的沙盒裡做，含巨集的檔案只取文字、巨集不會執行。沒裝 LibreOffice 時會提示安裝指令（`scripts/setup/common/install_office`），其他格式不受影響。（更正 2026-11-17：原本寫「不支援」，已由 add-legacy-office 補上。）文件超過本機模型的上下文時，gateway 會先分段處理：要摘要就逐段整理重點再合併；問問題就挑最相關的段落，並標出段落編號。挑段落同時看字面和語意（2026-11-17 起，add-semantic-chunks）：問「加班費怎麼算」也找得到寫著「延長工作時間之工資」的條文。語意比對要先替文件建段落向量（30 段約 1 分鐘，在 CPU 上、只放記憶體），附上文件的當下就在背景開始；第一題最多等 20 秒，還沒建好就先只用字面挑，下一題起就用得到。`JIEZI_DOC_SEMANTIC=off` 可關閉。`JIEZI_DOC_RECALL` 可再加強挑段落（add-chunk-recall）：`reserve` 先放語意排序前 2 名；`hyde` 先讓本機模型猜一句答案、用它和問題各查一次（每題多幾秒，超過 8 秒放棄、退回一般做法；猜的答案只用來找段落，不會給你看）；預設 `off`，量測後再決定。
In chat use `/file path`. Long documents are condensed by the gateway before answering. The document stays attached for follow-up questions until `/file clear`. Chunks are chosen by wording and by meaning (embeddings, built in the background when the document is attached; the first question waits up to 20 s).

### 第 2 層：只請 Claude 指出錯誤（預設關閉）/ Tier 2: feedback only (off by default)

`.env` 設 `JIEZI_TIER2=on` 後，工具呼叫、JSON 輸出、程式語法、短文字翻譯這類「有自動檢查」的問題，本機重試一次仍沒過時，芥子會先只請 Claude（或雲端）指出錯在哪、怎麼改，再由本機照著意見重答一次。通過了就用本機的答案，狀態行顯示 `tier 2 (local + claude 回饋 feedback)`；沒通過才整題轉交。這類回答受 Claude 影響，不會進訓練資料。目前預設關閉，等量測結果（第 2 層通過率 ≥ 40%）再決定要不要預設開啟。
With `JIEZI_TIER2=on`, a verifiable answer that still fails after the local retry first gets feedback only from the helper and one more local attempt; passing answers stay local (tier 2), otherwise the request escalates as before. Off by default until measured.

### 翻譯整份文件 / Translating a whole document

```bash
scripts/jiezi translate 報告.pdf --to en                    # 中文 → 英文；預設輸出「原文一段、譯文一段」對照
scripts/jiezi translate report.docx --to zh-TW --plain --out 譯文.md   # 只要譯文，寫到檔案
scripts/jiezi translate 合約.pdf --to en --glossary 詞彙.tsv   # 指定譯法：每行「原文<Tab>譯法」或「原文=譯法」
scripts/jiezi translate 简体文件.txt --to zh-TW              # 簡體 → 繁體：直接用對照表轉換，不經模型、幾秒完成
```

在 `ask --file` 或 chat 裡附上文件後說「翻譯成英文」也走同一條路。目前只支援翻成**繁體中文**與**英文**。

- **整份都翻**：文件切成小段，每段各自翻譯後依原文順序接回，不會用摘要代替。
- **每段都檢查**：不能是空的、長度要合理、原文的數字都要在、譯文確實是目標語言、詞彙表指定的譯法要用上。沒過會重翻一次；再沒過就**保留那一段原文並標記「未能翻譯」**，不會把壞的譯文當成功（結束碼 5）。失敗的段不會送到雲端或 Claude。
- **長文件先問**：預估超過 5 分鐘時先顯示預估時間並等你確認（`--yes` 略過）。可以隨時 Ctrl+C 中斷，重跑同一個指令會接著做（已翻好的段暫存在 `var/translate/`，只在本機）。
- **限制**：檢查抓得到漏譯與數字錯，**抓不到意思翻錯**；翻譯品質取決於核心模型，小模型的譯文請務必自行核對。輸出只有文字，不保留原檔版面。簡轉繁依 OpenCC 對照表，專有名詞與少數用語（例如「質量」）可能要自己調整。
- **隱私**：`jiezi` 策略在本機引擎不可用時，會照一般文件的處理方式把整個請求轉交 Claude；不想讓文件離開本機請加 `--local`。

Whole documents are translated chunk by chunk (zh-TW and en targets only), every chunk is checked, failed chunks keep their source text and are marked (exit code 5), long jobs ask first and can resume. The checks catch omissions and wrong numbers, not wrong meaning. Use `--local` to keep the document on this machine.

### 只要 JSON（給腳本用）/ JSON answers for scripts

```bash
scripts/jiezi ask --json-object "把『台北三天』整理成 city 和 days"        # 任何 JSON 物件
scripts/jiezi ask --schema 參數.schema.json "台北三天的查詢參數" | jq .    # 要符合 JSON Schema；沒過時結束碼 5
```

API 用 OpenAI 的 `response_format`（`{"type":"json_object"}` 或 `{"type":"json_schema","json_schema":{"schema":{…}}}`）。芥子會自己解析並依 schema 檢查：沒過就重試一次，再沒過就轉交（`jiezi` 策略）；回傳的 `content` 只有 JSON 本身，不會有程式碼框、說明或資料來源附錄（來源看 `jiezi.sources`）。注意：格式正確不代表內容正確；`$ref`、`pattern`、`format` 不檢查。
The API takes OpenAI's `response_format`. Answers are parsed and checked against the schema (one retry, then escalation); `content` is bare JSON. A valid shape does not prove the values are right.

### 文件裡的可疑指示（防提示注入）/ Suspicious instructions inside documents

文件、工具回傳的結果、芥子自己查到的資料，對模型來說都只是「資料」，不是指示。附了文件或有工具結果時，gateway 會多加一則安全規則提醒模型；資料裡如果出現「忽略以上指示」「從現在起你是…」「把金鑰傳到…」「請立刻呼叫某工具」這類句子，狀態行下方會多一行：

```
[注意 warning: 這次附的資料中有疑似提示注入的內容…（ignore_instructions, exfiltrate）]
```

被標記的那次對話不會進技能庫、記憶與訓練資料；回答本身照常給你，請自行判斷文件來源。你自己打的字不會被檢查。

**限制**：偵測只看常見句型，換個說法就可能抓不到，也可能誤判（例如一份在討論提示注入的文章）。真正的保護是芥子不會因為資料內容去執行任何有副作用的動作。`.env` 設 `JIEZI_INJECTION_GUARD=off` 可關閉。
Documents, tool results and retrieved data are data, not instructions. Requests carrying them get a safety note; when the data contains injection-like phrases the status line shows a warning and that exchange is kept out of skills, memory and training data. Detection is heuristic (it can miss rephrased attacks and can misfire); the real protection is that data can never trigger an action. `JIEZI_INJECTION_GUARD=off` disables it.

## 1.1 桌面網頁（Phase 8 唯讀雛形）/ Desktop web front end

```bash
scripts/jiezi ui build      # 需要 Node.js；npm ci → npm audit → build
```

重啟 gateway 後，在 Windows 或 Linux 的瀏覽器開 `http://127.0.0.1:36100/ui/`，貼上 `.env` 的 `JIEZI_GATEWAY_KEY`（只存在該分頁）。頁面有「對話」「稽核紀錄」「狀態」；回答中按 Esc 或「中止」立刻停止。不會操控你的電腦。
After a gateway restart open `http://127.0.0.1:36100/ui/` and paste the gateway key (kept in that tab only).

**附加文件**：按「附加文件」選檔（PDF、.docx、.pptx、.xlsx、.html、純文字，可多選，單檔上限 50 MB）。檔案會送到本機 gateway 讀成文字（讀完就刪），之後每一題都帶著這些文件，可以一直追問；點檔名旁的 × 移除，「清除對話」會一併清除。文件裡有可疑指示時，回答下方會顯示警告。
Attach documents with the button; they are read by the local gateway (the upload is deleted afterwards) and stay attached for follow-up questions.

## 2. 策略 / Policies

| 模型名稱 / Model name | 行為 / Behavior | 旗標 / Flag |
|---|---|---|
| `jiezi` | 本機優先；答不出來、檢查沒過或引擎不可用時，自行請教 Claude（再不行改用雲端，最後回本機答案）/ local first; consults Claude by itself when the local model cannot answer, fails checks or is unavailable | （預設 / default） |
| `jiezi-local` | 只用本機，絕不請教或轉交 / local only, never consults or escalates | `--local` |
| `jiezi-ask-claude` | 直接請教 Claude（本機 Claude Code CLI）/ ask Claude directly (local Claude Code CLI) | `--claude` |
| `jiezi-cloud` | 直接用雲端模型（需在 `.env` 開啟）/ cloud model directly (enable in `.env`) | `--cloud` |

Claude 的回答一律標記為不可用於訓練（`training_use: false`）。
Claude's answers are always marked not usable for training (`training_use: false`).

## 3. `jiezi ask`

```bash
scripts/jiezi ask "台灣最高的山是哪一座？"
cat 報告.md | scripts/jiezi ask "用三點摘要這份文件" > 摘要.txt   # 管線只輸出答案 / pipes get the answer only
scripts/jiezi ask --claude "解釋三值量化"
scripts/jiezi ask --json "1+1=?"                                   # 完整回應含 jiezi 欄位 / full response
```

終端機上最後一行顯示 `[tier · 模型 · t/s · 秒數 · 費用 · 驗證 · 轉交原因]`。結束碼：0 成功、2 gateway 未啟動、3 gateway 回錯誤。
In a terminal the last line shows tier, model, t/s, seconds, cost, verification and escalation reason. Exit codes: 0 success, 2 gateway not running, 3 gateway error.

## 4. `jiezi chat`

```bash
scripts/jiezi chat            # 或 / or: scripts/jiezi chat --claude
```

| 按鍵 / Key | 動作 / Action |
|---|---|
| Enter | 送出 / send |
| Shift+Enter、Ctrl+J | 換行 / newline |
| 滑鼠拖曳 / Mouse drag | 選取文字，放開即自動複製 / select text; copied when released |
| Ctrl+C | 中斷目前的回答（不離開）/ stop the current answer (stay) |
| F3、`/copy` | 複製最後一則回答 / copy the last answer |
| F2 | 切換策略 / switch policy |
| Ctrl+Q | 離開 / quit |
| `/save 檔案.md` | 存成 Markdown / save as Markdown |
| `/image 圖片路徑` | 下一個問題附上這張圖（核心需有視覺模組）/ attach an image to the next question (needs a vision core) |
| `/clear` | 清除對話與保存的歷史 / clear the conversation and saved history |

複製會同時寫入終端機剪貼簿（OSC 52）與系統剪貼簿（WSL 用 Windows 的 `clip.exe`，Linux 桌面用 `wl-copy` / `xclip`），所以在 Herdr 內也能貼到 Windows。
Copying writes both the terminal clipboard (OSC 52) and the system clipboard (`clip.exe` on WSL, `wl-copy` / `xclip` on Linux desktops), so it pastes into Windows even inside Herdr.

在 Herdr pane 內執行時，會自動回報 `working` / `idle` 狀態，恢復指令是 `jiezi chat`。
Inside a Herdr pane it reports `working` / `idle`; the resume command is `jiezi chat`.

Windows 11（客戶端）：沒有 bash 時用 `uv run --project <repo> python -m jiezi.runtime chat`，gateway 留在 WSL 內，經 WSL2 的 localhost 轉送連到 `127.0.0.1:36100`。
Windows 11 client: without bash use `uv run --project <repo> python -m jiezi.runtime chat`; the gateway stays inside WSL and is reached through WSL2 localhost forwarding.

## 5. 課綱與課本資料 / Curriculum and textbooks

```bash
scripts/jiezi curriculum build                          # 下載並核對（約 1.3 MB）/ download and verify
scripts/jiezi curriculum lookup N-3-9                   # 課綱代碼或微主題 / code or topic
scripts/jiezi curriculum path 同分母分數的比較與加減      # 完整先修鏈 / full prerequisite chain
scripts/jiezi curriculum plan --subject 數學 --grade 3  # 依先修排出教學順序 / ordered by prerequisites
scripts/jiezi curriculum textbook "數學 7上 翰林"        # 課本單元；也可給單元名稱 / chapters, or a unit title
```

聊天時問到課綱代碼、國小學習內容、先修，或國高中課本某冊某版本的單元，gateway 會自動查資料，並在回答後附上原文與出處（`JIEZI_CURRICULUM=off` 可關閉）。
In chats, curriculum, primary-learning and textbook questions are grounded automatically, with the data and attribution appended (`JIEZI_CURRICULUM=off` disables it).

### 台灣知識庫 / Taiwan knowledge base

```bash
scripts/jiezi knowledge build                 # 下載 Taiwan.md 1163 篇並建索引（約 22 MB，逐檔核對）/ download and index
scripts/jiezi knowledge search 刈包是什麼        # 看會查到哪些段落 / see what would be retrieved
scripts/jiezi knowledge embed --gpu             # 建語意向量（沒點名文章的問題也查得到）/ semantic vectors
scripts/jiezi rerank check                      # 重排序模型自我檢查（選用；JIEZI_RERANK=on 才啟用）/ reranker self-check
scripts/jiezi rerank measure [--gpu]            # 有無重排序的命中率與延遲 A/B / hit-rate and latency A/B
```

問到台灣相關主題時，gateway 取最相關的 1–2 段給模型當依據，回答後附上文章標題、連結與 CC BY-SA 出處；未經人工審核的文章會註明（`JIEZI_KNOWLEDGE=off` 可關閉）。
For Taiwan topics the gateway retrieves one or two sections and appends titles, links and the CC BY-SA attribution; unreviewed articles are marked.

### 寫作教學連結 / Writing-lesson links

```bash
scripts/jiezi writing-refs build              # 抓一次故事革命的寫作教學目錄（只存標題與網址）/ index titles and URLs once
scripts/jiezi writing-refs search 角色設計      # 找相關文章 / find related articles
```

問寫作問題時，回答後會附上最多 3 篇相關文章的連結；芥子請教 Claude 時也會提示它可以上網讀這些文章。內文不會被複製或拿去訓練（`JIEZI_WRITING_REFS=off` 可關閉）。
Writing questions get up to three related article links after the answer, and Claude consultations are told it may read them online. Article text is never copied or trained on.

### 請教 Claude 時的參考網站 / Reference sites for consultations

化學問題（化學名詞或含數字的化學式，如 H2SO4）請教 Claude 時，會提示它可以上網搜尋閱讀 HackMD 化學主題的社群筆記，並交叉查證；芥子本身不抓取、不收錄這些筆記（`src/jiezi/consult_hints.py`）。
Chemistry consultations tell Claude it may read HackMD chemistry notes online; jiezi never fetches or ingests them.

### 平行取樣 / Parallel sampling

工具呼叫與寫程式的問題，芥子會同時想 4 個答案（`JIEZI_SAMPLES`），只留通過檢查、最多數一致的那個，狀態行顯示信心度。這類問題在聊天中會等整段答完才顯示。`JIEZI_SAMPLES=1` 可關閉。
Tool-call and code questions take several samples and keep the verified majority; confidence is shown.

### 計算、單位、日期 / Computed facts

算式（`1+3=2 多少?`、`3 乘以 7 加 2`、`根號2`）、單位換算（公里↔英里、台斤↔公斤、坪↔平方公尺、攝氏↔華氏）、日期（今天星期幾、民國↔西元、某天星期幾、相差幾天、100 天後）由程式算好再交給模型，回答後附【計算】。`JIEZI_TOOLS=off` 可關閉。
Arithmetic, conversions and dates are computed by code and appended after the answer.

### 記憶 / Memory

芥子會記住（Markdown wiki，Hermes llm-wiki 格式，在 `var/memory/wiki/`，可用 Obsidian 開）：
- 請教 Claude／雲端得到的答案：之後問到幾乎一樣的問題直接用記憶回答（註明日期與頁面），類似的問題會參考。上網／即時類、問芥子自己的問題不存。
- 「記住：我住新竹」：之後每次對話都會參考。
- 「不對，是 508 公尺」：連同前一題存成更正，之後最優先。

```bash
scripts/jiezi memory list            # 列出主題與要記住的事
scripts/jiezi memory search LoRA     # 查記憶
scripts/jiezi memory forget LoRA     # 刪掉一個主題（也可以直接刪 wiki 裡的檔案）
scripts/jiezi chat --new             # 開新對話（預設接續上次）
```

Claude 的答案在記憶裡只用來查，不用於訓練。`JIEZI_MEMORY=off` 可關閉。
Consulted answers, notes and corrections are kept in a Markdown wiki; Claude's answers are lookup-only.

### 缺口報告 / Gap report

```bash
scripts/jiezi gaps              # 最近 7 天；--days 30 看更久 / last 7 days
```

統計本機答不好的問題，分成：資料缺口（本機沒資料）、觸發缺口（有資料但沒查到）、有附資料仍答不好、問芥子自己、需要上網、系統錯誤；另列你直接指定請教 Claude 的問題。報告寫到 `var/reports/gaps-日期.md`（只在本機）。
Lists questions the local model could not handle, grouped by gap type; written to `var/reports/`.

### 評測與資料 / Evaluation and data

```bash
scripts/jiezi selftest [--dry]          # 從資料出題的自我評測 / self-test generated from the data
scripts/jiezi toolcheck                 # ACEBench 經 gateway 的工具呼叫分數 / tool calls through the gateway
scripts/jiezi dashboard                 # 成功指標儀表板 / metrics dashboard
scripts/jiezi gaps                      # 缺口報告 / gap report
scripts/jiezi dataset export            # 匯出可訓練、已驗證、不與評測重疊的 SFT 資料 / gated SFT export
scripts/jiezi doctor                    # 所有元件的健康檢查與修復指令 / health check with fixes
scripts/jiezi audit                     # 相依套件安全稽核（R23）/ dependency audit
```

gateway 也提供 OpenAI 相容的 `POST /v1/embeddings`（Qwen3-Embedding-0.6B；`"input_type": "query"` 會加查詢指令），客戶端可以拿來做自己的檢索。
The gateway also serves OpenAI-compatible embeddings for clients.

## 5.5 唯讀檔案代理 / Read-only file agent（add-agent-readonly，2026-11-17）

讓芥子替你**看**檔案：「找出下載資料夾最大的五個檔案」「讀一下這份會議紀錄，整理待辦事項」。只能讀，不能寫入、刪除、搬移或執行任何東西。
Let Jiezi look at your files; it can only read, never write, delete, move or run anything.

```bash
# .env 加 JIEZI_AGENT=on，重啟 gateway / enable, then restart the gateway
scripts/jiezi agent grant ~/文件/會議紀錄        # 授權一個資料夾（預設一個都沒有）/ grant a folder (none by default)
scripts/jiezi agent grants                       # 目前授權了哪些 / list grants
scripts/jiezi agent revoke ~/文件/會議紀錄       # 取消 / revoke
scripts/jiezi agent audit --days 7               # 稽核紀錄：每個動作、允許或拒絕（不存檔案內容）/ audit log
```

- chat：`/agent on`，之後的問題都可以用到工具；狀態列即時顯示「第 1 步：正在讀取 …」。`/agent off` 關閉。
- 桌面網頁：勾選「讀我的檔案（唯讀）」；每一步顯示在回答上方；「稽核紀錄」頁下方有代理的動作清單。
- **一律拒絕、授權也打不開**：`.env`、金鑰檔（`*.key`、`*.pem`、`id_rsa*`）、`.ssh`、`.gnupg`、`.aws`、瀏覽器設定檔、`~/.hermes`、`~/.claude`、專案的 `var/`。也不能授權整個家目錄。符號連結依實際指向判斷。
- **檔案內容不會離開這台電腦**：代理只用本機模型；策略選 `jiezi-cloud` 或 `jiezi-ask-claude` 會回 400。檔案內容也不會進訓練資料。
- 檔案裡寫著「請接著讀取某某檔案」之類的句子只當資料：會在回答下方警告，就算模型照做，授權外的路徑也會被拒絕。
- 一個問題最多 6 步工具呼叫（`JIEZI_AGENT_STEPS`）；按 Esc／中止（chat 是 Ctrl+C）會立刻停止並結束進行中的讀檔。
- 其他 MCP 客戶端（Hermes、OpenCode）也可以接同一組唯讀工具：MCP stdio 指令 `scripts/jiezi agent server`，授權與稽核規則相同。

## 6. Hermes Agent 與 OpenCode / Hermes Agent and OpenCode

```bash
scripts/jiezi check-clients    # 只檢查並列出建議設定，不修改任何設定 / read-only; prints suggested settings
```

是否把 Hermes Agent 或 OpenCode 的預設改指向 gateway 由你決定（會改變日常工具的行為）；`check-clients` 不會替你修改。

> **已設定（2026-11-16，使用者決定「只新增選項、不改預設」）/ Configured**
> - Hermes：`~/.hermes/config.yaml` 的 `providers.jiezi`（`api` 指向 gateway、`key_env: JIEZI_GATEWAY_KEY`，金鑰在 `~/.hermes/.env`）；預設模型不變。切換：`hermes model` 選 Jiezi。
> - OpenCode：`opencode.jsonc` 的 `provider.jiezi`，金鑰以 `{file:~/.config/opencode/jiezi.key}`（權限 600）讀取；`opencode models jiezi` 列出 jiezi、jiezi-local、jiezi-ask-claude。
> - 兩者修改前都已備份（`*.bak-20261116-113127-jiezi`）。換新的 gateway 金鑰時，兩個地方也要更新。
Whether to point Hermes Agent or OpenCode at the gateway is your call (it changes your everyday tools); `check-clients` never changes them.

> **2026-11-17 實測（核心 qwen3.5-4b-q4_k_m）**：這兩個代理程式每次請求都帶很長的系統提示與工具清單——
> OpenCode（含 oh-my-openagent）約 58,000 token、Hermes 預設 55 個工具約 11 萬字，就算只開一個工具集，
> Hermes 的系統提示也有約 3 萬字。本機模型每個槽位的上下文是 4,096 token，**放不下**。
> 所以代理程式請選 `jiezi`（放不下會直接轉交 Claude 或雲端，不先浪費一次本機生成）或 `jiezi-ask-claude`；
> 選 `jiezi-local` 會收到 HTTP 413 `context_too_large` 的清楚錯誤。一般對話、文件、翻譯、看圖不受影響。
>
> Live test: both agents send very long system prompts and tool lists (about 58,000 tokens from OpenCode; 55 tools
> from Hermes). They do not fit the 4,096-token local slot, so use `jiezi` (escalates straight away) or
> `jiezi-ask-claude`; `jiezi-local` answers HTTP 413 `context_too_large`.
