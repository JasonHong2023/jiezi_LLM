# 芥子客戶端 / Jiezi clients

> 規格 / Spec：`openspec/changes/add-cli`（cli）、`openspec/changes/add-gateway`（gateway）。

## 1. 啟動 gateway / Start the gateway

```bash
scripts/jiezi serve        # 前景執行，Ctrl-C 關閉 gateway 與引擎 / foreground; Ctrl-C stops it and the engine
scripts/jiezi status       # 狀態 / state
```

gateway 只綁 `127.0.0.1:36100`，所有請求都要帶 `.env` 裡的 `JIEZI_GATEWAY_KEY`（bootstrap 會自動產生；舊的安裝可用 `scripts/jiezi init-key`）。
The gateway binds only to `127.0.0.1:36100`; every request needs `JIEZI_GATEWAY_KEY` from `.env` (generated by bootstrap, or `scripts/jiezi init-key` on older installs).

## 2. 策略 / Policies

| 模型名稱 / Model name | 行為 / Behavior | 旗標 / Flag |
|---|---|---|
| `jiezi` | 本機優先；答不出來、檢查沒過或引擎不可用時，自行請教 Claude（再不行改用雲端，最後回本機答案）/ local first; consults Claude by itself when the local model cannot answer, fails checks or is unavailable | （預設 / default） |
| `jiezi-local` | 只用本機，絕不請教或轉交 / local only, never consults or escalates | `--local` |
| `jiezi-ask-claude` | 直接請教 Claude（本機 Claude Code CLI）/ ask Claude directly (local Claude Code CLI) | `--claude` |
| `jiezi-cloud` | 直接用雲端模型（需在 `.env` 開啟）/ cloud model directly (enable in `.env`) | `--cloud` |

Claude 的回答一律標記為不可用於訓練（`training_use: false`）。
Claude's answers are always marked not usable for training (`training_use: false`).

## 3. `jiezi ask`

```bash
scripts/jiezi ask "台灣最高的山是哪一座？"
cat 報告.md | scripts/jiezi ask "用三點摘要這份文件" > 摘要.txt   # 管線只輸出答案 / pipes get the answer only
scripts/jiezi ask --claude "解釋三值量化"
scripts/jiezi ask --json "1+1=?"                                   # 完整回應含 jiezi 欄位 / full response
```

終端機上最後一行顯示 `[tier · 模型 · t/s · 秒數 · 費用 · 驗證 · 轉交原因]`。結束碼：0 成功、2 gateway 未啟動、3 gateway 回錯誤。
In a terminal the last line shows tier, model, t/s, seconds, cost, verification and escalation reason. Exit codes: 0 success, 2 gateway not running, 3 gateway error.

## 4. `jiezi chat`

```bash
scripts/jiezi chat            # 或 / or: scripts/jiezi chat --claude
```

| 按鍵 / Key | 動作 / Action |
|---|---|
| Enter | 送出 / send |
| Shift+Enter、Ctrl+J | 換行 / newline |
| Ctrl+C | 中斷目前的回答（不離開）/ stop the current answer (stay) |
| F2 | 切換策略 / switch policy |
| Ctrl+Q | 離開 / quit |
| `/save 檔案.md` | 存成 Markdown / save as Markdown |
| `/clear` | 清除對話 / clear the conversation |

在 Herdr pane 內執行時，會自動回報 `working` / `idle` 狀態，恢復指令是 `jiezi chat`。
Inside a Herdr pane it reports `working` / `idle`; the resume command is `jiezi chat`.

Windows 11（客戶端）：沒有 bash 時用 `uv run --project <repo> python -m jiezi.runtime chat`，gateway 留在 WSL 內，經 WSL2 的 localhost 轉送連到 `127.0.0.1:36100`。
Windows 11 client: without bash use `uv run --project <repo> python -m jiezi.runtime chat`; the gateway stays inside WSL and is reached through WSL2 localhost forwarding.

## 5. Hermes Agent 與 OpenCode / Hermes Agent and OpenCode

```bash
scripts/jiezi check-clients    # 只檢查並列出建議設定，不修改任何設定 / read-only; prints suggested settings
```

是否把 Hermes Agent 或 OpenCode 的預設改指向 gateway 由你決定（會改變日常工具的行為）；`check-clients` 不會替你修改。
Whether to point Hermes Agent or OpenCode at the gateway is your call (it changes your everyday tools); `check-clients` never changes them.
