# 芥子客戶端 / Jiezi clients

> 規格 / Spec：`openspec/changes/add-cli`（cli）、`openspec/changes/add-gateway`（gateway）。

## 1. 啟動 gateway / Start the gateway

```bash
scripts/jiezi start        # 在背景啟動，關掉終端機也不會停 / background; survives closing the terminal
scripts/jiezi stop         # 停止 gateway 與引擎 / stop the gateway and the engine
scripts/jiezi logs         # 最近的記錄 / recent logs
scripts/jiezi status       # 狀態 / state
scripts/jiezi serve        # 前景執行（除錯用），Ctrl-C 關閉 / foreground (debugging); Ctrl-C stops it
```

`jiezi chat` 與 `jiezi ask` 發現本機 gateway 沒開時，會自動在背景啟動它。
`jiezi chat` and `jiezi ask` start the local gateway in the background when it is not running.

gateway 只綁 `127.0.0.1:36100`，所有請求都要帶 `.env` 裡的 `JIEZI_GATEWAY_KEY`（bootstrap 會自動產生；舊的安裝可用 `scripts/jiezi init-key`）。
The gateway binds only to `127.0.0.1:36100`; every request needs `JIEZI_GATEWAY_KEY` from `.env` (generated by bootstrap, or `scripts/jiezi init-key` on older installs).

## 2. 策略 / Policies

| 模型名稱 / Model name | 行為 / Behavior | 旗標 / Flag |
|---|---|---|
| `jiezi` | 本機優先；答不出來、檢查沒過或引擎不可用時，自行請教 Claude（再不行改用雲端，最後回本機答案）/ local first; consults Claude by itself when the local model cannot answer, fails checks or is unavailable | （預設 / default） |
| `jiezi-local` | 只用本機，絕不請教或轉交 / local only, never consults or escalates | `--local` |
| `jiezi-ask-claude` | 直接請教 Claude（本機 Claude Code CLI）/ ask Claude directly (local Claude Code CLI) | `--claude` |
| `jiezi-cloud` | 直接用雲端模型（需在 `.env` 開啟）/ cloud model directly (enable in `.env`) | `--cloud` |

Claude 的回答一律標記為不可用於訓練（`training_use: false`）。
Claude's answers are always marked not usable for training (`training_use: false`).

## 3. `jiezi ask`

```bash
scripts/jiezi ask "台灣最高的山是哪一座？"
cat 報告.md | scripts/jiezi ask "用三點摘要這份文件" > 摘要.txt   # 管線只輸出答案 / pipes get the answer only
scripts/jiezi ask --claude "解釋三值量化"
scripts/jiezi ask --json "1+1=?"                                   # 完整回應含 jiezi 欄位 / full response
```

終端機上最後一行顯示 `[tier · 模型 · t/s · 秒數 · 費用 · 驗證 · 轉交原因]`。結束碼：0 成功、2 gateway 未啟動、3 gateway 回錯誤。
In a terminal the last line shows tier, model, t/s, seconds, cost, verification and escalation reason. Exit codes: 0 success, 2 gateway not running, 3 gateway error.

## 4. `jiezi chat`

```bash
scripts/jiezi chat            # 或 / or: scripts/jiezi chat --claude
```

| 按鍵 / Key | 動作 / Action |
|---|---|
| Enter | 送出 / send |
| Shift+Enter、Ctrl+J | 換行 / newline |
| 滑鼠拖曳 / Mouse drag | 選取文字，放開即自動複製 / select text; copied when released |
| Ctrl+C | 中斷目前的回答（不離開）/ stop the current answer (stay) |
| F3、`/copy` | 複製最後一則回答 / copy the last answer |
| F2 | 切換策略 / switch policy |
| Ctrl+Q | 離開 / quit |
| `/save 檔案.md` | 存成 Markdown / save as Markdown |
| `/clear` | 清除對話 / clear the conversation |

複製會同時寫入終端機剪貼簿（OSC 52）與系統剪貼簿（WSL 用 Windows 的 `clip.exe`，Linux 桌面用 `wl-copy` / `xclip`），所以在 Herdr 內也能貼到 Windows。
Copying writes both the terminal clipboard (OSC 52) and the system clipboard (`clip.exe` on WSL, `wl-copy` / `xclip` on Linux desktops), so it pastes into Windows even inside Herdr.

在 Herdr pane 內執行時，會自動回報 `working` / `idle` 狀態，恢復指令是 `jiezi chat`。
Inside a Herdr pane it reports `working` / `idle`; the resume command is `jiezi chat`.

Windows 11（客戶端）：沒有 bash 時用 `uv run --project <repo> python -m jiezi.runtime chat`，gateway 留在 WSL 內，經 WSL2 的 localhost 轉送連到 `127.0.0.1:36100`。
Windows 11 client: without bash use `uv run --project <repo> python -m jiezi.runtime chat`; the gateway stays inside WSL and is reached through WSL2 localhost forwarding.

## 5. 課綱與課本資料 / Curriculum and textbooks

```bash
scripts/jiezi curriculum build                          # 下載並核對（約 1.3 MB）/ download and verify
scripts/jiezi curriculum lookup N-3-9                   # 課綱代碼或微主題 / code or topic
scripts/jiezi curriculum path 同分母分數的比較與加減      # 完整先修鏈 / full prerequisite chain
scripts/jiezi curriculum plan --subject 數學 --grade 3  # 依先修排出教學順序 / ordered by prerequisites
scripts/jiezi curriculum textbook "數學 7上 翰林"        # 課本單元；也可給單元名稱 / chapters, or a unit title
```

聊天時問到課綱代碼、國小學習內容、先修，或國高中課本某冊某版本的單元，gateway 會自動查資料，並在回答後附上原文與出處（`JIEZI_CURRICULUM=off` 可關閉）。
In chats, curriculum, primary-learning and textbook questions are grounded automatically, with the data and attribution appended (`JIEZI_CURRICULUM=off` disables it).

### 台灣知識庫 / Taiwan knowledge base

```bash
scripts/jiezi knowledge build                 # 下載 Taiwan.md 1163 篇並建索引（約 22 MB，逐檔核對）/ download and index
scripts/jiezi knowledge search 刈包是什麼        # 看會查到哪些段落 / see what would be retrieved
```

問到台灣相關主題時，gateway 取最相關的 1–2 段給模型當依據，回答後附上文章標題、連結與 CC BY-SA 出處；未經人工審核的文章會註明（`JIEZI_KNOWLEDGE=off` 可關閉）。
For Taiwan topics the gateway retrieves one or two sections and appends titles, links and the CC BY-SA attribution; unreviewed articles are marked.

### 寫作教學連結 / Writing-lesson links

```bash
scripts/jiezi writing-refs build              # 抓一次故事革命的寫作教學目錄（只存標題與網址）/ index titles and URLs once
scripts/jiezi writing-refs search 角色設計      # 找相關文章 / find related articles
```

問寫作問題時，回答後會附上最多 3 篇相關文章的連結；芥子請教 Claude 時也會提示它可以上網讀這些文章。內文不會被複製或拿去訓練（`JIEZI_WRITING_REFS=off` 可關閉）。
Writing questions get up to three related article links after the answer, and Claude consultations are told it may read them online. Article text is never copied or trained on.

### 請教 Claude 時的參考網站 / Reference sites for consultations

化學問題（化學名詞或含數字的化學式，如 H2SO4）請教 Claude 時，會提示它可以上網搜尋閱讀 HackMD 化學主題的社群筆記，並交叉查證；芥子本身不抓取、不收錄這些筆記（`src/jiezi/consult_hints.py`）。
Chemistry consultations tell Claude it may read HackMD chemistry notes online; jiezi never fetches or ingests them.

## 6. Hermes Agent 與 OpenCode / Hermes Agent and OpenCode

```bash
scripts/jiezi check-clients    # 只檢查並列出建議設定，不修改任何設定 / read-only; prints suggested settings
```

是否把 Hermes Agent 或 OpenCode 的預設改指向 gateway 由你決定（會改變日常工具的行為）；`check-clients` 不會替你修改。
Whether to point Hermes Agent or OpenCode at the gateway is your call (it changes your everyday tools); `check-clients` never changes them.
